# Future work

The current project intentionally keeps the runtime simple and offline-first. Possible successor work:

- tune tool-specific retrieval queries on larger representative corpora;
- create dedicated SOC and ISO retrieval benchmark sets;
- evaluate hybrid lexical + embedding retrieval;
- add automatic document-domain classification with explicit human override;
- add approved offline PDF/DOCX/XLSX parsers;
- evaluate a second smaller model only after equivalent benchmark/quality/resource validation;
- integrate deployment-specific TLS and enterprise authentication;
- add real compiler/engine validation where approved YARA/Suricata/Zeek tooling is available.
